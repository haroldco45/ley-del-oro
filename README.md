# Ley del Oro · Calculadora por densidad

PWA para estimar la **ley (milésimas)**, los **quilates** y el **oro fino** de una barrita de oro
usando una balanza gramera y un vaso de agua. Método tomado del video de referencia.

## Fórmula

1. **PS** = peso seco de la barra (g)
2. **PM** = peso en agua: vaso con agua sobre la balanza, tarar, sumergir la barra colgada de un hilo (g de agua desplazada)
3. **Densidad** = PS ÷ PM
4. **Ley** = Densidad × 999,9 ÷ 19,32
5. **Quilates** = Ley × 24 ÷ 1000
6. **Oro fino** = PS × Ley ÷ 1000

Ejemplo del video: 53,61 ÷ 2,98 = 17,99 → 17,99 × 999,9 ÷ 19,32 = **931,06** → ≈ 22,35 K

## Publicar en GitHub Pages

1. Suba todos los archivos a la raíz de un repositorio (por ejemplo `ley-oro`).
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. En `index.html` reemplace `TU-USUARIO` (y `ley-oro` si el repo se llama distinto) en las etiquetas `og:url`, `og:image` y `twitter:image`, para que la imagen salga al compartir el enlace.
